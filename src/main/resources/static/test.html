Create a responsive navbar

Easy

Using HTML and CSS, create a responsive navigation bar. The navbar should include a logo on the left, navigation links in the center, and a mobile menu toggle button. On mobile devices (screens smaller than 768px), the navigation links should collapse into a hamburger menu. The navbar should have a clean, modern design with proper spacing and hover effects.

Code Editor HTML, CSS, JavaScript

Add CSS animation to a button

Medium

Create an animated button using CSS. The button should have a hover effect that includes a scale transformation, color transition, and a subtle shadow animation. Add a loading state animation with a spinning icon when clicked. The button should be accessible and maintain good usability across different devices.

Code Editor HTML, CSS
3

Write a JS dark/light mode toggle

Medium

Implement a dark/light mode toggle functionality using JavaScript. The toggle should switch between light and dark themes, persist the user's preference in localStorage, and apply the theme to the entire page. Include smooth transitions between themes and ensure the toggle button has appropriate visual feedback.

Code Editor HTML, CSS, JavaScript
4

Form validation using JS

Hard

Create a comprehensive form validation system using JavaScript. The form should validate email format, password strength, required fields, and custom validation rules. Display real-time error messages, prevent form submission with invalid data, and provide clear feedback to users. Include accessibility features and proper error handling.

Code Editor HTML, CSS, JavaScript
5

Grid layout using CSS Grid

Easy

Using CSS Grid, create a responsive card layout. The grid should display 3 cards per row on desktop, 2 cards per row on tablet, and 1 card per row on mobile. Each card should have equal height, proper spacing, and maintain aspect ratios. Include hover effects and ensure the layout is accessible.
